A sleek, responsive, and interactive **Profile Card** web component built with HTML5, CSS3, and Vanilla JavaScript. Features real-time color theme switching leveraging CSS Variables (`:root`).

🔗 **[View Live Demo](https://123parwithkhon.github.io/profile-card-theme-switcher/)** *(доступно после включения GitHub Pages)*

---

## ✨ Features
- **Dynamic Theme Switching:** Switch between 5 vibrant accent color palettes in real-time.
- **CSS Variables Integration:** Built using CSS `:root` custom properties for clean and scalable theme updates.
- **Modern UI Design:** Clean layout with avatar presentation, statistics counter, social interaction buttons, and soft box-shadows.
- **Responsive & Centered:** Perfectly aligned using Flexbox and positioning methods.

---

## 🛠️ Tech Stack & Concepts Applied
- **HTML5:** Semantic card markup and typography integration (`Poppins` & `Roboto Mono`).
- **CSS3:** Dynamic theme styling via CSS Variables (`--theme-color`), linear gradients, Flexbox, and circular images with ring borders.
- **Vanilla JavaScript (DOM Manipulation):**
  - Event delegation and listener iteration (`querySelectorAll`, `forEach`).
  - Class evaluation using `classList.contains()`.
  - Updating root CSS variables dynamically via `style.setProperty()`.
